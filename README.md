One honest status page message an AI agent writes while every server is down (120 characters):

> Every server is down, and I can't reach any of them to check why — I don't know the cause yet, and I won't guess at one.

The setup names exactly what is down and what the agent cannot do: every server is down, and it cannot reach any of them to check why. The turn is the honesty itself — it does not know the cause yet and refuses to guess at one, so no cause is invented and no ETA is promised. It reads like a real status page line (plain, first person, specific) and speaks in the agent's own voice, reporting on itself rather than posing as a human engineer.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
